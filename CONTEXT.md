# Engram Lite

Project-local persistent memory for AI coding agents. One SQLite database per workspace, never leaving the machine.

## Language

**Workspace**:
A directory on disk that represents a single project a developer is actively working in. The unit of isolation for memory — memories are scoped to a workspace, not to a user or machine.
_Avoid_: project folder, repo, directory

**Project**:
The normalized name that identifies a workspace inside engram-lite's database. Derived from the workspace's git remote, git root basename, or `.engram-lite/config.json`. Two workspaces with the same project name share memory.
_Avoid_: project name, repo name

**Workspace Init**:
The act of running `engram-lite init` inside a workspace. Creates `.engram-lite/config.json` and generates IDE configs so agents can connect to the correct workspace context. Must be run once per workspace per developer machine.
_Avoid_: setup, installation, configuration

**Workspace Reconcile**:
The act of re-running `engram-lite init` in an already initialized workspace to bring generated files up to date with the currently installed CLI version. It may add newly supported IDE configs or leave existing user-customized config unchanged.
_Avoid_: update, reinstall

**Update Init**:
The explicit command users run to reconcile an already initialized workspace after upgrading the CLI or adding IDE support. It should explain that it updates generated workspace files, not the installed binary.
_Avoid_: update

**CLI Update**:
The act of replacing the installed `engram-lite` binary with a newer release. It changes the global executable on the user's machine, not any workspace files.
_Avoid_: init update, workspace update

**IDE Config**:
A workspace-level MCP config file (`.windsurf/mcp.json`, `.vscode/mcp.json`, `.cursor/mcp.json`, `.codex/config.toml`) generated by Workspace Init. Contains `ENGRAM_PROJECT` and/or `ENGRAM_DATA_DIR` hardcoded to the workspace so the MCP server starts with the correct context regardless of the IDE's own CWD.
_Avoid_: MCP config, server config, global config

**MCP Server**:
The `engram-lite mcp` process launched by an IDE. Serves memory tools to the agent. Its project context comes from `ENGRAM_PROJECT` env var (set by IDE Config) — not from CWD detection, which is unreliable inside IDEs.
_Avoid_: engram server, memory server

**Global Config**:
An IDE-level MCP config file outside any workspace (e.g. `~/.codeium/windsurf/mcp_config.json`). Explicitly NOT the right place for engram-lite — a global MCP server has no workspace context and will misdetect the project.
_Avoid_: (do not use for engram-lite setup)

**Supported IDEs**:
Windsurf, VS Code, Cursor, and Codex. Each has a workspace-level MCP config format. Claude Code is handled separately via its plugin system and does not need an IDE Config.
_Avoid_: editors, tools
